# Contributing

Bug reports and ideas are welcome as issues.

Mach is free for personal use, and paid for businesses (see the README). To keep that possible, code is only merged
from people who agree that Ahmed Khaleel may license their contribution under any terms, including commercial ones.
Opening a pull request means you agree to that for the changes in it, and that they are yours to give.

    cd Core && swift test          # the engine's tests
    cd App && xcodegen generate    # then build the Mach or MachPhone scheme in Xcode
